# Welcome to PIT Common project
This is the primary code repository for PIT Common Libraries.

The Production Insurance Tools Common project supports the Ministry of Agriculture suite of applications developed to help farmers manage the risks associated with crop damage or loss due to naturally occurring perils.

## Technologies used

* [Angular](https://angular.io/)
* [Java](https://www.java.com/en/)

### CI/CD for DEV/TEST/PROD Deployments

The PIT Common project is built and deployed via Github actions.
